NATIV gbrain Drive Backup

This is a private backup utility for the NATIV company workspace. It stores encrypted gbrain database backups in a dedicated private Google Drive folder, and verifies recovery in an isolated environment.

Only the company account authorizes this utility. It is not offered as a public backup service. It requests Google Drive drive.file access only: access to files created by or explicitly opened with this application.
