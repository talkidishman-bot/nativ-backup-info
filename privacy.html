Privacy and data use

Updated 26 October 2026. NATIV gbrain Drive Backup is a private company backup utility operated for the company account. Contact: info@mm-ai.co.

The utility checks the authorized Google account identity and available storage. It uses Drive file access to create a private backup folder and to upload, list, read, and verify encrypted backup files there. The requested scope also permits modification and trashing of application-authorized files. The current backup workflow does not enable automatic backup deletion.

Backup contents are encrypted locally in the GitHub Actions worker before being uploaded to Google Drive. Google Drive stores encrypted backup objects and associated technical file metadata. Encryption does not conceal all file names, sizes, or access metadata from the storage provider.

OAuth client credentials and refresh credentials are stored in the company's existing Bitwarden secrets project and used by the company's existing private GitHub Actions backup workflow. GitHub processes the source backup data during export and recovery testing. Google account credentials are used only for the approved backup functionality and are not included in public logs or public website content.

Google user data is not sold, used for advertising, or used to train general-purpose AI models. Access is limited to operating, securing, and verifying the backup function. The utility's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Backups remain in the private company Drive folder until an authorized company operator applies a separate retention decision or deletes them. Current operation does not apply automatic deletion. Authorization can be revoked through the Google account permissions controls; revocation does not itself delete existing backups. Credential access can also be revoked through the company secret-management controls.
